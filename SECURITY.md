# Security Policy

Please report security issues privately.

Do not open public GitHub issues for vulnerabilities, API key exposure, auth bypasses, token storage issues, or permission issues.

Report security issues through the contact channel listed on https://shareone.vip, or use GitHub private vulnerability reporting if it is enabled for this repository.

Please include:

- Affected extension version.
- Reproduction steps.
- Expected and actual behavior.
- Potential impact.
- Screenshots or logs with secrets redacted.

ShareOne for VS Code stores authorization tokens using VS Code Secret Storage. Never paste API keys, access tokens, or authorization callback URLs into public issues.
